# Version 1.0.0 - Thesis Artifact Release

This release publishes the curated academic repository, final thesis materials, YOLO-format dataset archive, and trained model checkpoints for five YOLO11 variants.

## Included Release Assets

- `Data-DATN-22207062.zip`: 3,140 images and matching YOLO labels.
- `weights-YOLO11n.zip`: best and last YOLO11n checkpoints.
- `weights-YOLO11s.zip`: best and last YOLO11s checkpoints.
- `weights-YOLO11s-preprocessing.zip`: best and last preprocessing-variant checkpoints.
- `weights-YOLO11m.zip`: best and last YOLO11m checkpoints.
- `weights-YOLO11l.zip`: best and last YOLO11l checkpoints.
- Thesis PDF, editable thesis DOCX, and defense slides.
- `SHA256SUMS.txt`: release-asset integrity checksums.

The thesis and slides are preserved in their original Vietnamese submission language; the repository documentation and release guidance are written in United States English.

## Result Summary

YOLO11s was selected with precision 0.87, recall 0.69, F1 0.77, mAP50 0.80, and mAP50-95 0.64 on the held-out test set.
